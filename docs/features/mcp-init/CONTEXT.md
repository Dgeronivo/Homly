## Glossary

<!-- term · 1-sentence canonical definition -->
- event — запланована подія, що або відбувається у визначені часові межі (наприклад, відвідування лікаря), або триває цілий день (наприклад, виїзд в інше місто).
- family — група людей, які мають спільний перегляд подій (events) один одного та спільний доступ до todo-item і shopping-list.
- shopping-list — структурований список покупок, спільний для family.
- todo-item — справа, яку потрібно виконати.
- user — окрема людина, що є членом family та має власний профіль у застосунку.
